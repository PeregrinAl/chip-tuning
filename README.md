# Как заполнить сайт

## 1. Заглушки
Замените сразу во всех файлах: в VS Code `Ctrl+Shift+H` → «Заменить все».

Осталось заполнить:

| Заглушка | Чем заменить | Пример |
|---|---|---|
| `+7 (918) 755-99-82` | телефон, как его показывать | +7 (900) 123-45-67 |
| `79187559982` | телефон, только цифры | 79001234567 |
| `[ИНН]` | ИНН самозанятого | 450000000000 |

Уже заполнено: имя «Олег», «Олег Александрович» внизу страниц, адрес «Курган, ул. Комиссаров, 98/3, р-н Северный», часы «Пн–Сб 10:00–19:00».
Адрес открывается в 2ГИС. Если адрес изменится, поменяйте и текст, и ссылку `2gis.ru/kurgan/search/...` во всех файлах.
Если поменяются часы, исправьте их и в `index.html`, в блоке `application/ld+json`: там они записаны в формате `Mo-Sa 10:00-19:00`.

## 2. Фото
Сейчас на сайте стоят бесплатные фото с Unsplash в формате WebP. По их лицензии их можно использовать на коммерческом сайте без указания автора.
Чтобы поставить своё фото, сохраните его в формате WebP и положите в `photos/` **с тем же именем** поверх старого. Код менять не нужно.
Перевести JPG в WebP можно бесплатно, например на squoosh.app: качество 60–70, ширина 1000 px (для `hero.webp` — 1200 px).

## 3. Отзывы
Отзывы находятся в `index.html`, в блоках `<figure class="review">`. Чтобы добавить отзыв, скопируйте любой блок `<figure>…</figure>` и замените текст.
На компьютере видно три отзыва. Если их больше, сами появятся стрелки для прокрутки.
Оценка указана на всех страницах: `4,7` в тексте и `--r:4.7` в звёздах (звёзды закрашиваются по этому числу). Если на Авито она изменится, исправьте её на сайте. Число отзывов специально не указано: оно меняется часто.

## 4. Из чего состоит сайт
```
*.html          страницы (лежат в корне, от этого зависят их адреса)
assets/
  style.css     оформление
  site.js       меню на телефоне, кнопка «наверх», тахометр, появление карточек, карусель отзывов
  bg-circuit.svg  фон «дорожки платы» (цвет линий — параметр stroke в файле)
  fonts/        шрифт Unbounded (лежит на сайте, Google не используется)
photos/         фотографии (WebP)
```

## 5. Публикация
Нужны все `.html`, а также папки `assets` и `photos`. Папку `.claude` загружать не нужно, она исключена в `.gitignore`.

## 6. Что убрано ради безопасности (юридически)
- Услуги по отключению экологических систем (Евро-2, катализатор, EGR, мочевина AdBlue, сажевый фильтр, лямбда-зонд) убраны с сайта целиком.
- Вместо «дилерская диагностика» — «на дилерском оборудовании», чтобы не выглядело, будто мастер официальный дилер.
- Ключи и иммобилайзер — только владельцу, по СТС/ПТС и паспорту (написано на странице ключей и в карточке на главной).
- Фото, где главное — логотип марки (Mercedes, Nissan), заменены на фото без логотипов.
- Внизу каждой страницы — «Самозанятый Олег Александрович, ИНН [ИНН]» (закон об информации и закон о защите прав потребителей).
- Перед запуском для клиентов перенесите сайт на российский хостинг (Beget, Timeweb): GitHub — иностранный сервер.
